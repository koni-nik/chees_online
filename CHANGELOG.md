# Changelog - Исправления кода

## Критичные исправления безопасности ✅

1. **CORS настройки**
   - Добавлена конфигурация через переменные окружения
   - По умолчанию разрешены только локальные домены
   - Добавлен флаг `ALLOW_ANY_ORIGIN` для разработки

2. **Валидация входных данных**
   - Добавлена валидация `player_id` и `room_id` через регулярные выражения
   - Защита от инъекций и некорректных данных
   - Валидация в path параметрах WebSocket endpoints

3. **Обработка ошибок**
   - Улучшена обработка конкретных типов ошибок (ValidationError, KeyError, ValueError, TypeError)
   - Более информативные сообщения об ошибках

## Исправленные баги ✅

1. **Сохранение игры при отключении**
   - Исправлена логика определения `white_id` и `black_id`
   - Правильная обработка отключившегося игрока

2. **Race condition в matchmaking**
   - Добавлена защита от одновременного удаления игроков из очереди
   - Обработка исключений при удалении

3. **Утечки памяти**
   - Добавлена автоматическая очистка пустых комнат
   - Периодическая очистка неактивных комнат (каждые 5 минут)

## Рефакторинг ✅

1. **Менеджеры для управления состоянием**
   - `RoomManager` - управление игровыми комнатами
   - `TournamentRoomManager` - управление турнирными комнатами
   - `ConnectionManager` - управление WebSocket соединениями
   - Все глобальные переменные вынесены в классы

2. **Логика undo**
   - Добавлен метод `undo_move()` в `ChessGame`
   - Правильный откат хода вместо пересоздания игры
   - Сохранение состояния игры

3. **Конфигурация**
   - Создан файл `config.py` для всех настроек
   - Поддержка переменных окружения
   - Расширяемость для новых версий фронтенда и тем

## Улучшения качества кода ✅

1. **Удалены неиспользуемые импорты**
   - Удален `heapq`

2. **Использование констант**
   - Заменены магические числа на константы из `config.py`
   - Использование `DEFAULT_TIME_CONTROL` вместо `600`

3. **Реализован TODO**
